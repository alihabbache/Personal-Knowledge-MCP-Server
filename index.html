Features

Everything you need, nothing you don't

note:///

Notes Index Resource

Browse your entire vault as a live URI listing. Every note is discoverable, including nested subfolders.

note:///{path}

Note Resource Template

Read any individual note by URI on demand. Works with Obsidian links and Notion export paths.

search_notes

Full-Text Search Tool

Search across all .md files. Returns note titles, URIs, and the exact matching lines — up to 50 results.

get_note

Get Note Tool

Fetch a note by exact URI or fuzzy filename match. The AI summarizes the full content inline — no copy-paste needed.

Security

Designed in, not bolted on

Your notes are personal. Security was a first-class requirement from the start.

🔒

Read-only filesystem

Only fs.readFile and fs.readdir. No write, delete, or execute operations exist in the codebase.

🛡️

Path traversal protection

Every URI is resolved and verified to be inside NOTES_DIR. A crafted note:///../../etc/passwd is blocked and returns an error.

🚫

No network listener

Runs over stdio — no open port, no HTTP server. Only your MCP client can communicate with it.

👁️

Hidden files excluded

Files and directories starting with . are skipped. Your .env and .ssh folders are never touched.

🔑

Zero credentials

No API keys, tokens, or passwords required. Nothing sensitive ever passes through the server.

📦

Sandboxed to NOTES_DIR

The vault walker only descends into the single directory set at startup. It cannot be redirected at runtime.

⚠️ One trade-off to know: When get_note returns content, it enters your LLM's context. If you use a cloud-hosted LLM (Claude, GPT-4), that content leaves your machine. The server is fully local — the LLM may not be. Use a local model via Ollama for fully private processing.
Get Started

Up and running in 3 steps

1

Clone and build

git clone https://github.com/alihabbache/Personal-Knowledge-MCP-Server.git
cd Personal-Knowledge-MCP-Server
npm install && npm run build
2

Register with your MCP client

Add this to your MCP config (e.g. ~/.bob/settings/mcp.json for Bob, or Claude Desktop's config file):

{
  "mcpServers": {
    "personal-knowledge": {
      "command": "node",
      "args": ["/path/to/Personal-Knowledge-MCP-Server/build/index.js"],
      "env": {
        "NOTES_DIR": "/path/to/your/notes"
      }
    }
  }
}
3

Talk to your notes

Restart your AI client and start asking in plain English:

"List all my notes"
"Search my notes for 'system design'"
"Summarize my sprint planning note"
"What have I written about product strategy?"
