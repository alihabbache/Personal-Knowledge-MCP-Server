I Built a Server That Gives Your AI Access to Your Personal Notes

Your knowledge base is your most valuable asset. Here's how I made mine queryable through natural language — without sending a single file to the cloud.

The Problem I Kept Running Into

I take a lot of notes. Sprint recaps, architecture decision records, product ideas, research summaries — all living in Markdown files across a folder structure I built over years.

But every time I sat down with an AI assistant to think through a problem, I had to start from scratch. The AI had no idea what I'd already written. I was copy-pasting context into every chat, searching my vault manually, switching apps mid-thought.

My knowledge was trapped. The AI was blind.

So I built a fix.

What I Built: Personal Knowledge MCP Server

An open-source MCP server that exposes your Markdown notes — Obsidian vaults, Notion exports, or any folder of .md files — as live resources and tools for any AI assistant.

Once connected, you talk to your notes the same way you talk to your AI:

"Search my notes for 'system design'"
"Summarize my note on async architecture"
"What have I written about product strategy?"
"List all my notes"

No copy-paste. No app switching. No wondering if you already thought about this.

How It Works

The server is built on the Model Context Protocol (MCP) — an open standard for connecting AI assistants to external data sources and tools. It runs locally as a stdio process, meaning:

  • Your notes never leave your machine
  • The AI never has direct filesystem access
  • The server only reads what's inside your designated notes folder

The architecture is clean:

Your Prompt
    ↓
MCP Client (Bob / Claude Desktop)
    ↓  JSON-RPC 2.0 over stdio
Personal Knowledge MCP Server
    ↓  fs.readFile() — read only
Your Notes (Markdown files on disk)

How to Use It

Step 1 — Clone and build

git clone https://github.com/alihabbache/Personal-Knowledge-MCP-Server.git
cd Personal-Knowledge-MCP-Server
npm install && npm run build

Step 2 — Register with your MCP client

Add this to your MCP config (e.g. ~/.bob/settings/mcp.json for Bob, or Claude Desktop's config):

{
  "mcpServers": {
    "personal-knowledge": {
      "command": "node",
      "args": ["/path/to/Personal-Knowledge-MCP-Server/build/index.js"],
      "env": {
        "NOTES_DIR": "/path/to/your/notes"
      }
    }
  }
}

Step 3 — Talk to your notes

That's it. Restart your AI client and start asking questions in plain English.

What I Learned Building This

MCP is genuinely powerful. The protocol is simple — JSON-RPC 2.0 over stdio — but the developer experience of registering a tool and having it show up in an AI client immediately is remarkable. The feedback loop is fast.

The value is in the retrieval, not the storage. Most people already have great notes. The missing piece is a layer that makes those notes accessible to the tools they're already using.

Local-first matters. Running on stdio means zero network calls, zero cloud dependency, zero privacy risk. Your notes stay on your machine. That's not a compromise — it's a feature.
